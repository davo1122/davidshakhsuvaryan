## 📦 Проекты

### 🏦 [mini-bank-api](https://github.com/shach1r/mini-bank-api)
Backend банковского сервиса на **FastAPI**: регистрация, вход по **JWT**, банковские счёта, хранение в PostgreSQL. Миграции через Alembic, запуск в Docker.
`FastAPI` · `PostgreSQL` · `SQLAlchemy` · `Alembic` · `Docker` · `JWT`

### 🤖 [AI Notes Assistant](https://github.com/shach1r/AI-Notes-Assistant-project)
CLI-приложение, которое с помощью **LLM (Groq API)** превращает обычные заметки в структуру: краткое summary, автоматическое выделение задач из текста, сохранение в JSON.
`Python` · `Groq API` · `LLM` · `JSON` · `CLI`

### 📚 [book-parser](https://github.com/shach1r/book-parser)
Парсер каталога товаров: обход пагинации, заход в карточку товара, чистка и дедупликация данных, выгрузка в форматированный **Excel** (лист «Каталог» + лист «Сводка») и опционально в **Google Sheets**. Есть retry при сбоях сети и вежливые задержки.
`requests` · `BeautifulSoup4` · `pandas` · `openpyxl` · `gspread`

### 📝 [smart-todo-cli](https://github.com/shach1r/smart-todo-cli)
Консольный менеджер задач: приоритеты (low/medium/high), дедлайны, авто-определение просроченных задач, сортировка по важности и сроку, цветной вывод, автосохранение.
`Python` · `JSON` · `colorama` · `OOP`

### 🔐 [Dimmer — генератор паролей](https://github.com/shach1r/Dimmer)
GUI-приложение на **Tkinter** для генерации безопасных паролей: настраиваемая длина и наборы символов, копирование в буфер обмена, история генераций.
`Python` · `Tkinter`

### 🐧 [college-linux-course](https://github.com/shach1r/college-linux-course)
Учебные материалы и скрипты по администрированию Linux (Ubuntu Server).
`Shell` · `Linux`
